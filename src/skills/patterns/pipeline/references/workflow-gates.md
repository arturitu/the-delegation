# Workflow Gates: Project Progress

## Gate 1: Discovery -> Design
- All requirements are documented.
- User intent is clear.
- Core entities are identified.

## Gate 2: Design -> Development
- Architecture diagram is approved.
- Technical stack is confirmed.
- Task breakdown is complete.

## Gate 3: Development -> Review
- Unit tests pass.
- All tasks are "Done".
- Linter is clean.
